## 🏛 Архитектурные правки

### 5. Типология нод (macro/meso/micro)

Визуализировать уровень каждой ноды:
- MACRO: радиус 1.2, жирная подпись, всегда видна
- MESO: радиус 0.7, видна при среднем зуме
- MICRO: радиус 0.3, только при сильном зуме

### 6. Типология рёбер (conceptual/historical/practical/resonance/opposition)

Каждый тип ребра — свой стиль:
- **historical** → сплошная, тёплый цвет
- **conceptual** → пунктир, холодный
- **practical** → точки, зелёный
- **opposition** → красный, пульсация
- **resonance** → тонкая, полупрозрачная (пользовательские)

### 7. Истории привязаны к рёбрам (НЕ к нодам)

Каждая `Story` должна иметь поле `edgeId` — прямая ссылка на ребро.  
Без fuzzy-матчинга. Без рандома.

## 👥 Админ-панель и модераторы (ВАЖНО)

### Концепция: многоуровневая система

Не один главный админ, а **сообщество модераторов** с разными правами.

**Роли:**
```
Super Admin (Нео)
  ├── может всё: добавлять/удалять любые ноды, рёбра, истории
  ├── назначать модераторов
  ├── промоутить field-ноды в atlas
  └── экспорт/импорт данных
       │
    Moderator (5-20 человек)
       ├── может добавлять ноды и рёбра (с пометкой "moderated")
       ├── может писать истории (с пометкой "verified" после апрува)
       ├── может модерировать field-ноды (апрув/отклонение)
       └── НЕ может удалять atlas-ноды
            │
         Contributor (сообщество)
            ├── может добавлять наблюдения в Поле
            ├── может резонировать / нести / писать истории
            └── может стать модератором (по репутации)
```

**Что модераторы могут делать:**
- Добавлять новые **ноды** с источниками (пруфами)
- Добавлять **рёбра** между существующими нодами (с описанием связи)
- Добавлять **истории** (проверенные, с ссылками)
- Писать **пруфы** (источники, цитаты, ссылки) к нодам
- Голосовать за промоушн field-ноды в atlas
- Модерировать контент от сообщества (апрув/отклонение)

**Админ-панель:**
- Скрытый роут `/admin` или кнопка для админов
- Экспорт данных в JSON → AI-агент анализирует
- Импорт изменённого JSON обратно → обновление БД
- Лог всех действий модераторов
- Статистика: кто сколько добавил, какие ноды растут

## 💾 База данных

**Стратегия (согласовано с Нео):**

```
┌──────────────────┐     ┌──────────────────────┐
│  GitHub Pages      │     │  Сервер (VPS)         │
│  (фронтенд)        │ ←─→ │  База данных + API    │
│  Vite build        │     │  PostgreSQL            │
│  CI/CD автоматом   │     │  FastAPI/Node.js API   │
```
