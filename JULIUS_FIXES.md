## 🎨 ВИЗУАЛЬНЫЕ РЕЖИМЫ (добавлено 18:35)

### Монохромный режим
Кнопка `🎨` переключает цветной / чёрно-белый режим.
- CSS filter: grayscale(100%) на канвас — самое простое
- Или замена цветов в Three.js материалах

### Fullscreen режим
Кнопка `⛶` в хедере:
- Прячет весь UI
- Граф на весь экран
- Медленная авторотация камеры (OrbitControls.autoRotate = true)
- Escape или тап → выход

### Авторотация
- По умолчанию: 0.5°/сек
- При drag юзером: пауза на 10 сек, потом плавно возобновляется

### Performance Mode (для проектора)
- Fullscreen + увеличенный Bloom + скрытый курсор
- Идеально для перформансов
